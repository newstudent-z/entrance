# 错题本 v2 · 数学为主，存查 + 知识点总结

**已上线（2026-10-25）：https://codexme.top/cuoti/** —— 部署在阿里云 ECS（Ubuntu 22.04），systemd 服务名 `cuotiben`（程序在 /opt/cuotiben/，本机监听 18080），经 nginx 在 codexme.top 主域名下以子路径 /cuoti/ 反代（HTTPS，和 /git/、/jupyter/ 同款部署方式）。首次打开需输一次性设置码自设密码。nginx 原配置备份在服务器 /root/nginx-backups/deeplearning.bak-20261025-cuoti。

定位（按 sen 的实际用法定的）：**把做错的题存下来，方便随时翻看回顾、沉淀知识点总结**。
不搞强制复习、不搞打卡队列——没有到期提醒，没有欠账感，想看的时候自己翻。

零依赖：Python 3 + SQLite（Ubuntu 自带），进程约 20-30MB，小内存服务器可跑。

## 核心功能
- **错题库**：按科目 / 板块 / 状态筛选，全文搜索（题目、知识点、来源、我的总结都能搜），最新在前，典型题置顶
- **数学一板块已细化**：高数（函数极限连续 / 一元微分 / 一元积分 / 多元微分 / 二重积分 / 微分方程 / 无穷级数）、线代（行列式与矩阵 / 向量与方程组 / 特征值与二次型）、概率（随机变量与分布 / 数字特征 / 统计基础）；另保留 408 / 英语一 / 政治
- **每道题带「知识点」字段**：如 洛必达法则、矩阵的秩、条件概率——这是汇总的锚点，存题时顺手填（有历史输入提示）
- **知识点总结页**：自动按出错次数汇总每个知识点（错得多的 = 薄弱点，排最前），每个知识点下可写自己的总结（公式 / 结论 / 易错点），一键跳到该知识点下的全部错题
- **轻状态**：只有「还没弄懂 / 已弄懂」一键切换，外加「⭐ 典型题」标记——纯手动，没有任何调度强迫
- **随机翻几道**：🎲 从「还没弄懂」里随机抽 5 道，随便看看，不想看关掉就行
- **拍照存题 + 图片编辑**：手机拍照/图库选图后自动弹出裁剪器（拖动选区、四角缩放、框外拖动重画、旋转 90°），把题目以外的废画面切掉再存，确认后仍会压缩到最宽 1600px；编辑错题时可对原图再裁剪、换一张或删图，文字内容也全部可改
- **题目与答案分区规划**：录入表单按「📖 题目（文字+题目图）→ ✍️ 我当时的作答 → ✅ 正确答案/解析（答案图+答案文字）→ 🧩 归纳（来源/错因/难度/总结）」分区；答案可以单独拍一张照片存（answer_image 字段，老库自动迁移）。查看卡片不再折叠：题目图在上、绿色「✅ 正确答案/解析」区块紧随其后直接展示答案图+文字，没补答案的题会显示虚线提醒块
- **备份**：页面一键导出 JSON（错题 + 知识点总结一起）；服务器端数据在 `data/cuoti.db` + `uploads/`
- **登录保护**：单用户密码 + 30 天会话

## 存储与容量（照片存哪）
- 照片目前存服务器本地 `/opt/cuotiben/uploads/`，上传前前端已压缩（最宽 1600px、JPEG），实测平均约 200-400KB/张。服务器 40G 盘、约 30G 空闲 ≈ 可存 8 万张量级，考研周期内（按每天 10 张算约 4300 张 ≈ 1.5GB）完全够用，统计页有实时用量和「还能存多少张」估算。
- 暂不上 OSS 的理由：现阶段纯属增加成本（虽小）、AccessKey 管理与改造复杂度，收益为零。图片路径在数据库里是独立字段，将来真要迁移 OSS（同地域华北2、内网上传、私有桶+签名 URL）写个脚本搬文件换地址即可，不用改用法。更划算的中间路线是先做好定期导出备份。

## 从 GitHub 更新（改完代码之后）

工作流：本地改代码 → `git push` 到这个仓库 → 服务器上拉取重启。

首次把服务器 `/opt/cuotiben/` 变成 git 仓库（只做一次，数据目录被 .gitignore 忽略，不会被覆盖/删除）：

```bash
cd /opt/cuotiben
git init && git remote add origin <这个仓库的地址>
git fetch origin && git reset --mixed origin/main   # 只对齐代码文件，不动 data/ 和 uploads/
git checkout -- app.py   # 如有冲突以仓库版为准
systemctl restart cuotiben
```

之后每次更新只需在服务器上跑：

```bash
cd /opt/cuotiben && bash update.sh
```

注意：**不要把 `data/`、`uploads/` 推上来**——数据库里有你的登录密码哈希和 AI API Key，照片也在 uploads 里。`.gitignore` 已经挡住了，`git add` 时别用 `-f` 强加。
